Plantilla Gratuita

Crea la web de tu refugio en 5 minutos

Consigue una página web moderna, profesional y autogestionable para tu protectora o asociación de animales de forma 100% gratuita.

Guía de Inicio Rápido

Sigue estos tres sencillos pasos para tener tu propia página web en marcha sin tocar una sola línea de código.

1

Haz Fork del Repositorio

Inicia sesión en tu cuenta de GitHub (si no tienes una, créala gratis en 1 minuto) y ve al repositorio original de esta plantilla. Haz clic en el botón Fork (en la esquina superior derecha) para crear una copia exacta en tu propia cuenta.

2

Activa tu Web Gratis (GitHub Pages)

Dentro de tu repositorio copiado, ve a la pestaña superior Settings (Configuración) y en el menú lateral izquierdo haz clic en Pages. En la sección Build and deployment, bajo el apartado Branch, selecciona la rama main (y la carpeta /root) y pulsa en Save. ¡Tu web estará publicada en pocos minutos en la dirección que te preocesione GitHub!

3

Personaliza y Sube tus Animales

Abre tu nueva URL pública y añade /admin.html al final de la dirección (ej: https://tu-usuario.github.io/tu-repo/admin.html). Inicia sesión con tu cuenta de GitHub y un Token de Acceso. ¡Listo! Ya podrás subir animales, fotos y editar los colores y textos de tu web sin programar nada.

Preguntas Frecuentes

¿Tiene algún coste de mantenimiento?

No. El alojamiento y despliegue del catálogo se realiza en los servidores de GitHub Pages, que ofrece alojamiento gratuito indefinido para proyectos personales y de ONGs.

¿Es seguro el panel de administración?

Sí. Al ser una web sin servidor central (estática), no guardamos tus contraseñas ni datos personales. Tu Token de Acceso se almacena exclusivamente en tu ordenador y se comunica de forma directa con los servidores seguros de GitHub.

¿Cómo consigo el Token de Acceso para el Admin?

Al entrar en la pantalla de administrador, verás un enlace directo para generar tu token. GitHub te guiará en un par de clics para crearlo y copiarlo de forma rápida.
